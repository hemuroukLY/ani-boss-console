# ANI BOSS Console 当前状态

> 本文件只记录当前功能状态、缺口和最近变更；开发规则以 `AGENTS.md` 及其引用的专项文档为准，产品与接口事实仍以对应 GitNexus 索引为准。

## 模块状态

- 平台运营总览：覆盖运营总览、容量、GPU 资源态势、AI 服务、知识库和平台告警；容量、GPU 清单与联动事件已接入 ANI，其余态势仍包含静态或演示数据。
- 租户管理：覆盖租户、配额策略、租户管理员、计费与详情流程；GPU 配额与预留已接入，其他管理流程仍以页面实现和前端状态为主。
- 资源池与基础设施：覆盖平台资源池、GPU、节点、存储、网络和镜像仓库运维；GPU 库存、占用、配额、预留与集群切分已接入 ANI，其余页面主要为静态展示或空态。
- 运维与可观测：平台健康和单组件实时日志已接入 ANI；领域监控、组件指标、Trace、告警和运维任务仍为静态、规划或占位状态。
- 平台计量与结算：GPU、CPU 和 Memory 用量已接入 ANI；Storage、Tokens、KB Queries、价格、账单、结算和导出尚未接入。
- 安全审计与合规：平台审计日志已接入 ANI；API Key 审计、推理调用审计和合规取证仍为规划页。
- 平台设置：平台账密登录和平台运营账号已完成前端接线；IdP、会话与安全策略仍为预留页。
- 平台集成与通知：运维 Webhook、企业通知和运营系统对接仍为占位页。

## 当前缺口

- 静态、演示、规划和占位页面不代表生产能力；缺少契约时保持禁用或空态，不模拟成功结果。
- 已完成前端接线的能力仍需在目标环境验证真实数据、错误处理、写后回读和外部依赖。
- GPU 管理仍缺设备级权威归属、指定卡分配、维护和平台调度能力。
- 租户生命周期、身份安全、完整计费结算，以及多数基础设施运营能力尚未形成真实后端闭环。
- 平台级监控、告警、Trace、跨组件日志检索和运维处置仍缺完整数据与操作能力。
- 平台运营账号、部分认证与通知能力仍受后端路由、权限或字段完整性限制。
- 部分大型页面和遗留领域状态仍需按业务边界逐步拆分、迁移。
